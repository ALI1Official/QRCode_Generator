# QR Code Generator

A simple QR code generator that runs entirely in your browser. No backend, no API,
no internet connection needed — just open the HTML file and go.

## What it does

* Type any text or link and turn it into a QR code.
* Or upload a small file (like a tiny icon) and it'll try to embed the file itself
directly inside the code.
* Pick your own colors for the QR code.
* Download the result as a PNG whenever you want.

## How to use it

1. Open `index.html` in any browser.
2. Pick the **Text / URL** tab or the **File** tab.
3. Type your text/link, or choose a file.
4. Hit **Generate QR Code**.
5. Hit **Download PNG** to save it.

That's it.

## Running it

No installs, no setup:

```bash
git clone https://github.com/ALI1Official/QRCode_Generator
cd QRCode_Generator-main
open qr-generator.html
```

Everything needed to generate the QR code is already inside the file, so it works
even with no internet connection at all.
